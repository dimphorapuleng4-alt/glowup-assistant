# GlowUp Assistant

Build a modern, responsive AI-powered small-business management platform called GlowBiz AI, designed specifically for a beauty salon that offers wigs, braids, nails, lashes, and other beauty services.

The application should be a single integrated dashboard, not separate unrelated applications. Its purpose is to help a salon owner manage daily business tasks, communicate professionally with customers, organize appointments/tasks, summarize notes, and use AI for business research and decision-making.

BRAND & VISUAL DESIGN

Use a premium, feminine, modern beauty-salon aesthetic.

Primary colors:

White

Soft/light pink

Black

Dark charcoal for secondary dark-mode surfaces

The application must support:

Light Mode

Dark Mode

A clearly visible theme toggle in the navigation/header

Smooth transitions between themes

Excellent contrast and accessibility in both modes

Use pink as the main accent color, black for important text/buttons, and white/light pink for backgrounds and cards in light mode.

Dark mode should use black/dark charcoal backgrounds with white text and elegant pink accents.

The design should feel like a high-end modern SaaS dashboard combined with a luxury beauty brand.

Use:

Rounded cards

Soft shadows

Elegant typography

Clean spacing

Modern icons

Subtle pink gradients

Smooth hover states

Professional animations, but do not overuse animations

AI MEETING NOTES SUMMARIZER

Create a meeting/call notes summarizer.

The user can paste long meeting notes into a text area.

The AI should extract:

Summary

A concise summary of the discussion.

Decisions

Important decisions that were made.

Action Items

Tasks that need to be completed.

Deadlines

Dates or deadlines mentioned in the notes.

People Responsible

Identify who is responsible for each action item when this information is available.

Example:

"Sarah will order new lash supplies by Friday."

The system should extract:

Task: Order new lash supplies Responsible: Sarah Deadline: Friday

Include a button:

"Add Action Items to Task Planner"

When clicked, extracted tasks should be added to the AI Task Planner.

This creates integration between the AI features.

RESPONSIBLE AI

Include a visible Responsible AI notice in Settings and relevant AI pages.

Use wording similar to:

"AI-generated content may contain errors or omissions. Review AI outputs before sending customer communications or making business decisions. Do not enter sensitive personal, financial, or confidential information unless appropriate and permitted."

The AI should:

Clearly identify generated content as AI-generated

Avoid pretending to have accessed information it did not access

Avoid inventing customer details

Avoid presenting uncertain business recommendations as guaranteed facts

Encourage the salon owner to verify important information

AI PROMPT ENGINEERING

Use structured prompts for each AI feature.

Do not simply send the user's text directly to the AI.

Each prompt should define:

Role

Business context

User request

Desired tone

Required output format

Constraints

Responsible AI instructions

For example, the email generator should use a structured system prompt similar to:

"You are an AI communication assistant for a professional beauty salon. Create concise, professional customer communications based only on the information provided by the user. Do not invent customer details, appointments, prices, services, or promises. Match the requested tone. Return a polished draft that the salon owner can review and edit before sending."

Use similar structured prompts for the meeting summarizer, task planner, research assistant, and chatbot.

TECHNICAL REQUIREMENTS

Build the application as a functional modern web application.

Use reusable components.

Create clean component architecture.

Use persistent state/database functionality where appropriate so tasks, customers, services, and saved AI results can persist.

Include realistic demo data so the application looks complete when first opened.

The application should feel like a real commercial SaaS product rather than a school project.

Prioritize functionality over unnecessary visual effects.

FINAL PRODUCT EXPERIENCE

The final product should feel like:

"ChatGPT + business manager + salon assistant"

but specifically designed for a small beauty salon.

The core value proposition should be:

"Spend less time managing your salon and more time serving your clients."

Make the interface polished enough for a real salon owner to use every day.
